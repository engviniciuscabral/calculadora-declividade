
# Calculadora de Declividade

Projeto simples desenvolvido em Python para
calcular a declividade entre dois pontos.

## Fórmula

Declividade (%) = (Desnível / Distância) * 100

## Como executar

Execute o arquivo calculadora_declividade.py
utilizando Python 3.
